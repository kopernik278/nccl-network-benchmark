# NCCL / RDMA Communication Benchmark

A systems-oriented GPU communication project for studying and benchmarking
collective communication used in distributed AI training.

## Goals

- Benchmark NCCL collective communication
- Measure latency and bandwidth
- Study GPU topology effects
- Compare intra-node and inter-node communication
- Study RoCE and InfiniBand
- Implement a simplified Ring AllReduce
- Profile communication behavior
- Investigate communication/computation overlap

## Planned Collectives

- Point-to-Point
- AllReduce
- AllGather
- ReduceScatter
- Broadcast
